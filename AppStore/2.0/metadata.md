# Batyrma 2.0: App Store metadata

Written by an App Store search specialist, Nov 2026. Character counts checked; App Store Connect counts characters, not bytes.

## Localizations
- **Apple has no Kazakh localization.** For the Kazakhstan storefront, Apple indexes only **English (U.K.)**. Without en-GB, it falls back to the app's primary language.
- **The KZ store shows ru copy** to Russian-language devices. Whether ru keywords are indexed in KZ isn't documented.
- **Add English (U.K.).** It carries KZ search, written in Cyrillic.

## Keyword evidence (App Store search suggestions, KZ storefront, 2026-11-25)
These are what the App Store suggests as people type in Kazakhstan; a suggestion only shows up if enough people search it.
- **Keyboard searches that exist:** казахская клавиатура, **казакша клавиатура** (top suggestion for "казакша"), казакша клавиатура айфон, казакша пернетакта, қазақша пернетақта, пернетакта, пернетақта, kazakh keyboard, qazaq keyboard, клавиатура казахский.
- **Big generic searches that cover us:** клавиатура айфон / клавиатура на айфон, казахский шрифт / казакша шрифт, казакша жазу.
- **Also searched:** қазақ тілі, qazaqsha, орфография (general Russian spelling, a partial fit since Batyrma checks Russian words), kazakh language.
- **No evidence of search volume:** автокоррекция, раскладка (only "раскладка плитки"), казахские буквы; т9 only matches itself. These were dropped.
- **Covered by combining fields:** Apple matches words across the name, subtitle and keywords of one localization. So "казакша" in the keywords plus "клавиатура" in the name matches "казакша клавиатура".
